# 小芽學堂 🌱

由 panjin 發起的繁體中文幼兒教育開源網站初版，供家長與幼教工作者免費使用、改作及分享。

## 內容
- 六個適合親子參與的活動，涵蓋繪本共讀、情緒表達、生活自理與探索遊戲。
- 可依分類篩選，展開材料與步驟。
- 響應式版面，無須註冊，無外部追蹤程式。

## 使用
直接用瀏覽器開啟 index.html。無相依套件、無須建置。

## Netlify 部署
將此資料夾內容放入公開 GitHub 儲存庫，再於 Netlify 匯入該儲存庫。使用隨附 netlify.toml；不需設定建置指令。
